# A Council skill is a SKILL.md, a typed function and its tests

A Council skill is a SKILL.md, a typed function and its tests. Graphs orchestrate; skills hold discipline.

**Conflict it settled.** The proposals use "skill" for workflows, deterministic functions and inferential reviews alike.

**Why.** One packaging format, smaller prompts through progressive disclosure, and skills Tom can test in Claude Code.

**Decided.** Settled in the consolidated charter of 10 November 2026.
