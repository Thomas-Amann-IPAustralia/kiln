# Evidence is matched to the question

Evidence is matched to the question. Authority settles what is required; measured results and working documentation settle how to build. An approved project decision binds the build until new evidence reopens it.

**Conflict it settled.** Solution, Governance, UX and Data-E rank sources differently, and Data-E puts project decisions above law. Tom notes that the most authoritative sources are often the most abstract.

**Why.** One authority ranking sends implementation questions to the least practical sources.

**Decided.** Tom, feedback of 7 October 2026.
