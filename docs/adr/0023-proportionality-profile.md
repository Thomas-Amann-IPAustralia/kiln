# Every solution carries a proportionality profile

Each solution carries a proportionality profile: who uses it, what data it touches, and whether it informs, acts or decides about people. Every expert sizes its work to it.

**Conflict it settled.** The proposals size controls to what each framework could require; Tom wants production quality without overburdening the process.

**Why.** An internal team tool and a public service should not carry the same controls.

**Decided.** Tom, feedback of 7 October 2026.
