# Generated code runs only in Modal sandboxes

Generated or agent-written code runs only in Modal sandboxes. The Oracle VM runs fixed Council services only.

**Conflict it settled.** Data-A allows analysis on the Oracle host; Security bars untrusted code from persistent hosts.

**Why.** A compromised persistent host on the tailnet exposes the whole Council.

**Decided.** Settled in the consolidated charter of 10 November 2026.
