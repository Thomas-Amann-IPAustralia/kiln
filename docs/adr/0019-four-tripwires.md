# Four tripwires replace the proposals' hard constraints

Four tripwires replace the proposals' hard constraints: real sensitive data in a build, exposed secrets, real-world actions before approval, and spend over budget.

**Conflict it settled.** Each proposal lists many hard constraints and escalation triggers; Tom prefers agents to start with too much authority rather than too little.

**Why.** These four cause harm or cost that cannot be undone. Everything else is fixed, decided or deferred with a reason.
