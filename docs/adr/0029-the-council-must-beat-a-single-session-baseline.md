# The Council must beat a single-session baseline before it grows

Before any agent beyond the chair and the Researcher is built, the three sample briefs go
through two paths: the Council's (chair, Researcher, one coding loop) and one plain Claude
Code session given the same briefs and the same rulebook. The two are compared on the
quality of the plan and the build, on cost and on elapsed time, by a rule committed before
either path runs. Phase 2 starts only if the Council's path wins by that rule, or Tom decides
to go on anyway.

**Conflict it settled.** The charter defines seven experts, but nothing tested whether
separate agents improve results over one well-instructed session (second opinion, D-007).

**Why.** A multi-agent design costs more to build, run and maintain. It should earn that cost
on measured results, as every other adopted design in the SOP does.

**Decided.** Tom, 17 November 2026 (D-008).
