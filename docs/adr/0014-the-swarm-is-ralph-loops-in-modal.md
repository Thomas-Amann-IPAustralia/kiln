# The swarm is a coding-agent CLI running Ralph loops in Modal

The swarm is a coding-agent CLI running Ralph loops in Modal, starting with one sequential loop.

**Conflict it settled.** The brief expects a swarm; Pocock finds one sequential agent usually enough; Huntley keeps Ralph to a single process.

**Why.** Reuses a proven loop instead of building a coding agent. Parallel loops come later, for unblocked tickets.

**Decided.** Settled in the consolidated charter of 10 November 2026.
