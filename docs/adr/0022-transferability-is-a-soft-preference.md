# Transferability is a soft preference

Transferability is a soft preference, ranked below speed and simplicity. The assurance case and repo records make handover possible with no extra build work.

**Conflict it settled.** The Solution proposal treats portability and exit as design drivers; Security and Governance prepare for formal assessment.

**Why.** Tom favours transferable systems, but not at a real cost to speed or complexity.

**Decided.** Tom, feedback of 7 October 2026.
