# Agents exchange typed artefacts, not conversation

Agents exchange typed artefacts, not conversation. A coding loop with an unclear ticket raises a typed question to the owning expert.

**Conflict it settled.** The brief has experts advise and confer; Huntley argues agent-to-agent chatter is not needed; the Solution proposal routes to keep discussion small.

**Why.** Cheaper, traceable, and approvals cannot be faked in prose.
