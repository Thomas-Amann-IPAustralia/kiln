# The Researcher discovers external datasets and hands over a manifest

The Researcher discovers external datasets and returns a Data Source Manifest, not a data stream. The Data Engineer profiles project data and the Data Analyst judges analytical fitness. One SDMX service serves everyone.

**Conflict it settled.** Data-A specifies its own ABS connectors and discovery layer; Data-E lists data discovery as a duty; the Researcher proposes a dataset discovery mode and a generic SDMX service.

**Why.** One client per provider, and a clean hand-off with exact queries and hashes.

**Decided.** Settled in the consolidated charter of 10 November 2026.
