# A human information owner sets classification

A human information owner sets classification. Governance records it; agents may only propose.

**Conflict it settled.** Security names Governance or a human; Data-E names Security or the information owner.

**Why.** Classification drives controls everywhere and is an organisational decision.

**Decided.** Settled in the consolidated charter of 10 November 2026.
