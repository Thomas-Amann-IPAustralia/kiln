# One shared profile, source registry, tool registry and decision store

One project profile, source registry, tool registry and decision store, each with domain sections or extensions.

**Conflict it settled.** Each proposal designs its own profile, source schema, registry or decision record format.

**Why.** Seven copies drift. One shared structure with owner fields stays consistent and queryable.

**Decided.** Settled in the consolidated charter of 10 November 2026.
